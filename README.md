# DLT Size Calculator

A simple React/Vite calculator for estimating left-sided double-lumen tube size from tracheal width on CXR and/or bronchial diameter on CT.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Upload this folder to a GitHub repo.
2. Go to Vercel > Add New > Project.
3. Import the GitHub repo.
4. Use default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Deploy.

## Add to iPhone Home Screen

Open the Vercel link in Safari > Share > Add to Home Screen.
